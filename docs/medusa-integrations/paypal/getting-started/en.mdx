# {frontmatter.title}

In this guide, you'll learn how to install and configure the PayPal payment provider for Medusa.

## Requirements

- Medusa v2.17.2 or later
- Node.js v22.23.4, v24.22.1, v26.12.1 or later
- A PayPal Business account – [sign in or create one](https://www.paypal.com/business)
- An app in the PayPal Developer Dashboard – [sign in or create one](https://developer.paypal.com/dashboard/applications)
- [Integration Module](/medusa-modules/integration)

## Configuration

Add the configurations of the Integration Module provider and of the Medusa Payment Module in your `medusa-config.ts` file of the Medusa Admin application:

```ts title="medusa-config.ts"
// ...
const PAYPAL_INTEGRATION_ID = "paypal-1"

module.exports = defineConfig({
  // ...
  plugins: [
    // ...
    {
      resolve: "@gorgo/medusa-integration",
      options: {
        encryptionKey: process.env.INTEGRATION_ENCRYPTION_KEY,
        providers: [
          {
            resolve: "@gorgo/medusa-payment-paypal/providers/integration-paypal",
            id: PAYPAL_INTEGRATION_ID,
            options: {},
          },
        ],
      },
    },
    {
      resolve: "@gorgo/medusa-payment-paypal",
      options: {},
    },
  ],
  modules: [
    // ...
    {
      resolve: "@medusajs/medusa/payment",
      options: {
        providers: [
          {
            resolve: "@gorgo/medusa-payment-paypal/providers/payment-paypal",
            id: "paypal",
            options: {
              id: PAYPAL_INTEGRATION_ID
            }
          },
        ],
      },
    },
  ],
})
```

The payment provider registered this way gets the id `pp_paypal_paypal`, and its webhook route is `/hooks/payment/paypal_paypal`.

Add environment variables with your secret `Encryption Key`:

```text title=".env"
INTEGRATION_ENCRYPTION_KEY=supersecret
```

## Webhook Setup

To properly handle payment notifications from PayPal, configure the webhook URL in your PayPal app as following:

1. Open your app under **Apps & Credentials**, with the **Sandbox** or **Live** environment that matches the plugin's settings.

2. In the **Webhooks** section, click **Add Webhook**.

3. Add a new webhook URL in the following format:
    ```text title="Webhook URL"
    https://{YOUR_MEDUSA_DOMAIN}/hooks/payment/paypal_paypal
    ```
    Change `{YOUR_MEDUSA_DOMAIN}` with your medusa store domain.

4. Subscribe the webhook to the `PAYMENT.AUTHORIZATION.CREATED` and `PAYMENT.CAPTURE.COMPLETED` events, and save it.

5. Copy the webhook ID and enter it in the **Webhook ID** field of the PayPal settings in Medusa Admin. **Test connection** then checks that the webhook exists in that environment and is subscribed to both events.

<Note type="warning">Without a webhook ID the plugin cannot verify PayPal's webhooks, so it ignores them. Payments still go through, but an order the storefront did not complete stays uncompleted, and a capture PayPal held for review stays authorized in Medusa.</Note>

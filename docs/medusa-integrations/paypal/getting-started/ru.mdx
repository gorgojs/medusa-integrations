# {frontmatter.title}

В этом руководстве вы узнаете, как установить и настроить платежный провайдер PayPal для Medusa.

## Требования

- Medusa v2.17.2 или новее
- Node.js v20 или новее
- Бизнес-аккаунт PayPal – [зарегистрируйтесь или войдите](https://www.paypal.com/business)
- Приложение в PayPal Developer Dashboard – [зарегистрируйтесь или войдите](https://developer.paypal.com/dashboard/applications)
- [Модуль интеграций](/medusa-modules/integration)

## Настройка

Добавьте конфигурации провайдера модуля интеграций и платежного модуля Medusa в файл `medusa-config.ts` в приложении Medusa Admin:

```ts title="medusa-config.ts"
// ...
const PAYPAL_INTEGRATION_ID = "paypal-1"

module.exports = defineConfig({
  // ...
  plugins: [
    // ...
    {
      resolve: "@gorgo/medusa-integration",
      options: {
        encryptionKey: process.env.INTEGRATION_ENCRYPTION_KEY,
        providers: [
          {
            resolve: "@gorgo/medusa-payment-paypal/providers/integration-paypal",
            id: PAYPAL_INTEGRATION_ID,
            options: {},
          },
        ],
      },
    },
    {
      resolve: "@gorgo/medusa-payment-paypal",
      options: {},
    },
  ],
  modules: [
    // ...
    {
      resolve: "@medusajs/medusa/payment",
      options: {
        providers: [
          {
            resolve: "@gorgo/medusa-payment-paypal/providers/payment-paypal",
            id: "paypal",
            options: {
              id: PAYPAL_INTEGRATION_ID
            }
          },
        ],
      },
    },
  ],
})
```

Так зарегистрированный платёжный провайдер получает id `pp_paypal_paypal`, а его вебхук приходит на роут `/hooks/payment/paypal_paypal`.

Добавьте переменную окружения с секретным ключом шифрования:

```text title=".env"
INTEGRATION_ENCRYPTION_KEY=supersecret
```

## Настройка вебхуков

Чтобы корректно обрабатывать платёжные уведомления от PayPal, настройте URL вебхука в своём приложении PayPal следующим образом:

1. Откройте своё приложение в разделе **Apps & Credentials**, выбрав окружение **Sandbox** или **Live**, как в настройках плагина.

2. В блоке **Webhooks** нажмите **Add Webhook**.

3. Добавьте новый URL вебхука в следующем формате:
    ```text title="Webhook URL"
    https://{YOUR_MEDUSA_DOMAIN}/hooks/payment/paypal_paypal
    ```
    Замените `{YOUR_MEDUSA_DOMAIN}` на домен вашего магазина Medusa.

4. Подпишите вебхук на события `PAYMENT.AUTHORIZATION.CREATED` и `PAYMENT.CAPTURE.COMPLETED` и сохраните его.

5. Скопируйте ID вебхука и введите его в поле **ID вебхука** в настройках PayPal в Medusa Admin. После этого кнопка **Проверить соединение** проверяет, что вебхук есть в этом окружении и подписан на оба события.

<Note type="warning">Без ID вебхука плагин не может проверить вебхуки PayPal и игнорирует их. Оплата при этом проходит, но заказ, который не оформила витрина, так и останется неоформленным, а списание, которое PayPal задержал на проверку, останется в Medusa авторизованным.</Note>

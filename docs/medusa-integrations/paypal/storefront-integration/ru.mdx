# {frontmatter.title}

Чтобы интегрировать платёжный провайдер PayPal в storefront (витрину магазина) [Medusa DTC Starter от Gorgo](https://github.com/gorgojs/medusa-dtc-starter), добавьте JS SDK PayPal, кнопку PayPal в ряд экспресс-оплаты над формой оформления заказа и ещё одну на шаг оплаты. Название и иконку PayPal стартер уже показывает при оформлении заказа через `paymentInfoMap` в `src/lib/constants.tsx` и строку `PaymentMethods.pp_paypal_paypal` во всех локалях, так что подписи менять не нужно.

Обе кнопки загружают SDK с Client ID и способом списания, которые бэкенд возвращает в `GET /store/paypal/config`. Клик создаёт платёжную сессию, а провайдер создаёт для неё заказ PayPal. В ряду экспресс-оплаты покупатель выбирает адрес в окне PayPal, витрина пересчитывает для него доставку и итог, а провайдер меняет сумму того же заказа PayPal. Когда покупатель подтверждает оплату, витрина получает его данные из `GET /store/paypal/orders/:order_id/payer`, сохраняет в корзине его контакты и адрес и оформляет заказ, при этом платёж списывается или блокируется.

Если покупатель закрыл вкладку после того, как PayPal списал деньги, заказ оформит вебхук `PAYMENT.CAPTURE.COMPLETED`. Подробнее в разделе [Настройка вебхуков](/medusa-integrations/paypal/getting-started#настройка-вебхуков).

Для витрины на Next.js нужно внести следующие изменения:

## Шаг 1: Установите JS SDK PayPal

Кнопки берутся из официальной React-обёртки JS SDK PayPal. Установите её в витрину:

<CodeTabs>
  <CodeTab label="yarn" value="yarn">
    ```bash
    yarn add @paypal/react-paypal-js@^8.9.2
    ```
  </CodeTab>
  <CodeTab label="npm" value="npm">
    ```bash
    npm install @paypal/react-paypal-js@^8.9.2
    ```
  </CodeTab>
</CodeTabs>

Версия 8 пакета `@paypal/react-paypal-js` загружает JavaScript SDK PayPal с `www.paypal.com/sdk/js` и даёт компонент `PayPalButtons`, колбэк `onShippingAddressChange` которого сообщает адрес, выбранный покупателем в окне PayPal.

## Шаг 2: Загрузите настройки PayPal и данные покупателя

Витрина получает от бэкенда две вещи. Публичные настройки говорят SDK, какое приложение и какой способ списания загрузить, а данные покупателя одобренного заказа заполняют корзину при экспресс-оплате.

Создайте [`src/lib/data/paypal.ts`](https://github.com/gorgojs/medusa-integrations/blob/main/examples/payment-paypal/apps/storefront/src/lib/data/paypal.ts) со следующим содержимым:

![Структура проекта Medusa Storefront после создания файла с загрузчиками данных PayPal](/static/paypal/storefront/src-lib-data-paypal.webp)

```ts title="src/lib/data/paypal.ts"
"use server"

import { sdk } from "@lib/config"
import { getAuthHeaders, getCartId } from "./cookies"

/** What the storefront needs to load the PayPal JS SDK, from `GET /store/paypal/config`. */
export type PayPalConfig = {
  provider_id: string
  client_id: string
  environment: "sandbox" | "live"
  intent: "capture" | "authorize"
}

/** The buyer of an approved PayPal order, from `GET /store/paypal/orders/:id/payer`. */
export type PayPalPayer = {
  amount: { currency_code: string; value: string } | null
  email: string | null
  phone: string | null
  shipping_address: {
    first_name: string | null
    last_name: string | null
    address_1: string | null
    address_2: string | null
    city: string | null
    province: string | null
    postal_code: string | null
    country_code: string | null
    phone: string | null
  } | null
}

/**
 * The public PayPal settings of the only PayPal integration, or null while it is
 * not configured. The client ID and the intent change only in the Admin, so the
 * answer is cached for a minute.
 */
export async function getPayPalConfig(): Promise<PayPalConfig | null> {
  return sdk.client
    .fetch<{ config: PayPalConfig }>("/store/paypal/config", {
      method: "GET",
      next: { revalidate: 60 },
    })
    .then(({ config }) => config)
    .catch(() => null)
}

/**
 * The contact and the shipping address the buyer chose in PayPal, and the amount
 * they approved. The backend answers only for an order created for this cart.
 */
export async function getPayPalPayer(orderId: string): Promise<PayPalPayer> {
  const cartId = await getCartId()
  if (!cartId) {
    throw new Error("No existing cart found for the PayPal order")
  }

  const { payer } = await sdk.client.fetch<{ payer: PayPalPayer }>(
    `/store/paypal/orders/${encodeURIComponent(orderId)}/payer`,
    {
      method: "GET",
      query: { cart_id: cartId },
      headers: { ...(await getAuthHeaders()) },
      cache: "no-store",
    }
  )
  return payer
}
```

`getPayPalConfig` возвращает `null`, если у бэкенда нет включённой и полностью настроенной интеграции PayPal, и тогда кнопки скрыты. `getPayPalPayer` передаёт id корзины. Бэкенд отвечает только по заказу, созданному для платёжной коллекции этой корзины, поэтому витрина не может прочитать чужой адрес по id заказа. Поле `amount` в ответе содержит сумму, которую покупатель одобрил в PayPal. Обе функции читают единственную интеграцию PayPal в магазине. Если их несколько, передавайте `provider_id` параметром запроса в оба роута.

## Шаг 3: Загрузите SDK PayPal

Обеим кнопкам нужен SDK, загруженный с одним и тем же Client ID, способом списания и валютой, поэтому их оборачивает один компонент.

Создайте [`src/modules/checkout/components/paypal-scope/index.tsx`](https://github.com/gorgojs/medusa-integrations/blob/main/examples/payment-paypal/apps/storefront/src/modules/checkout/components/paypal-scope/index.tsx) со следующим содержимым:

![Структура проекта Medusa Storefront после создания файла с обёрткой SDK PayPal](/static/paypal/storefront/src-modules-checkout-components-paypal-scope-index.webp)

```tsx title="src/modules/checkout/components/paypal-scope/index.tsx"
"use client"

import { getPayPalConfig, type PayPalConfig } from "@lib/data/paypal"
import { PayPalScriptProvider } from "@paypal/react-paypal-js"
import { unstable_rethrow } from "next/navigation"
import { type ReactNode, useEffect, useState } from "react"

// One request per page, shared by every PayPal button on it.
let configRequest: Promise<PayPalConfig | null> | null = null

/** The PayPal settings, `undefined` while they load and `null` without a PayPal integration. */
export const usePayPalConfig = () => {
  const [config, setConfig] = useState<PayPalConfig | null | undefined>(undefined)

  useEffect(() => {
    let active = true
    configRequest ??= getPayPalConfig().catch(() => null)
    configRequest.then((value) => {
      if (active) setConfig(value)
    })
    return () => {
      active = false
    }
  }, [])

  return config
}

/**
 * True for the control-flow error a placed order's `redirect()` throws. The
 * router follows the redirect on its own, so a PayPal callback that meets it
 * returns instead of reporting a failure over the placed order.
 */
export const isNavigation = (error: unknown) => {
  try {
    unstable_rethrow(error)
    return false
  } catch {
    return true
  }
}

/**
 * Loads the PayPal JS SDK for the buttons inside it, with the client ID and the
 * intent the backend creates orders with and the cart's currency. Keyed by the
 * currency, because the provider reads its options once and a change inside a
 * mounted provider leaves the buttons blank.
 */
export default function PayPalScope({
  currencyCode,
  onUnavailable,
  children,
}: {
  currencyCode?: string | null
  /** Called when the store has no PayPal integration configured. */
  onUnavailable?: () => void
  children: ReactNode
}) {
  const config = usePayPalConfig()

  useEffect(() => {
    if (config === null) onUnavailable?.()
  }, [config, onUnavailable])

  if (!config) {
    return null
  }

  const currency = (currencyCode || "usd").toUpperCase()
  return (
    <PayPalScriptProvider
      key={currency}
      options={{
        clientId: config.client_id,
        currency,
        intent: config.intent,
        components: "buttons",
      }}
    >
      {children}
    </PayPalScriptProvider>
  )
}
```

SDK загружается с валютой корзины, и при её смене компонент перемонтируется, потому что `PayPalScriptProvider` читает параметры один раз и иначе оставил бы SDK со старой валютой. `isNavigation` распознаёт `redirect()`, которым заканчивается оформленный заказ. Встретив его, колбэк PayPal завершается без ошибки поверх оформленного заказа.

## Шаг 4: Создайте кнопку оплаты

{/* TODO: screenshot of the PayPal button at the payment step */}

На шаге оплаты кнопка PayPal заменяет кнопку оформления заказа, когда покупатель выбирает PayPal.

Создайте [`src/modules/checkout/components/payment-button/providers/paypal.tsx`](https://github.com/gorgojs/medusa-integrations/blob/main/examples/payment-paypal/apps/storefront/src/modules/checkout/components/payment-button/providers/paypal.tsx) со следующим содержимым:

![Структура проекта Medusa Storefront после создания файла с кнопкой оплаты PayPal](/static/paypal/storefront/src-modules-checkout-components-payment-button-providers-paypal.webp)

```tsx title="src/modules/checkout/components/payment-button/providers/paypal.tsx"
"use client"

import { isPaypal } from "@lib/constants"
import { startExpressPayment } from "@lib/data/express-checkout"
import ErrorMessage from "@modules/checkout/components/error-message"
import PayPalScope, {
  isNavigation,
} from "@modules/checkout/components/paypal-scope"
import { PayPalButtons, usePayPalScriptReducer } from "@paypal/react-paypal-js"
import { type PaymentProviderButtonProps, usePlaceOrder } from "../shared"

function PayPalButtonsInner({
  cart,
  notReady,
  cartUpdating,
  "data-testid": dataTestId,
}: PaymentProviderButtonProps) {
  const [{ isResolved, isRejected }] = usePayPalScriptReducer()
  const { setSubmitting, errorMessage, setErrorMessage, completeOrder } =
    usePlaceOrder()

  const providerId =
    cart.payment_collection?.payment_sessions?.find((s) =>
      isPaypal(s.provider_id)
    )?.provider_id ?? "pp_paypal_paypal"

  if (isRejected) {
    return <ErrorMessage error="payment failed" data-testid={dataTestId} />
  }
  if (!isResolved) {
    return (
      <div className="h-12 rounded-md bg-ui-bg-component" aria-hidden="true" />
    )
  }

  return (
    <div data-testid={dataTestId}>
      <PayPalButtons
        disabled={notReady || cartUpdating}
        style={{
          layout: "vertical",
          color: "gold",
          shape: "rect",
          label: "paypal",
          height: 48,
        }}
        // A new session at the click, so the PayPal order carries the cart's
        // total and address as they are when the customer pays.
        createOrder={async () => {
          setErrorMessage(null)
          const data = await startExpressPayment(providerId, {
            shipping_address: cart.shipping_address,
          })
          const orderId = data.paypal_order_id
          if (typeof orderId !== "string" || !orderId) {
            throw new Error("PayPal payment session has no order")
          }
          return orderId
        }}
        onApprove={async () => {
          setSubmitting(true)
          try {
            await completeOrder()
          } catch (err) {
            if (isNavigation(err)) return
            throw err
          }
        }}
        onCancel={() => setSubmitting(false)}
        onError={(err) => {
          setErrorMessage(err instanceof Error ? err.message : "payment failed")
          setSubmitting(false)
        }}
      />
      <ErrorMessage
        error={errorMessage}
        data-testid="paypal-payment-error-message"
      />
    </div>
  )
}

/** The PayPal button at the payment step, in place of the order button. */
const PayPalPaymentButton = (props: PaymentProviderButtonProps) => (
  <PayPalScope currencyCode={props.cart.currency_code}>
    <PayPalButtonsInner {...props} />
  </PayPalScope>
)

export default PayPalPaymentButton
```

`createOrder` создаёт новую платёжную сессию в момент клика, поэтому заказ PayPal содержит итог и адрес корзины на момент оплаты, и PayPal показывает этот адрес, а не спрашивает его. `onApprove` оформляет заказ через `usePlaceOrder`, тот же хук, что у остальных кнопок оплаты.

## Шаг 6: Добавьте PayPal в ряд экспресс-оплаты

{/* TODO: screenshot of the express checkout row with the PayPal button */}

Ряд экспресс-оплаты стартера показывает кнопку каждого платёжного провайдера из своего реестра, если провайдер включён в регионе корзины. Как устроен ряд и что получает кнопка, описано в разделе [Настройка экспресс-оплаты](/tools/medusa-dtc-starter/setup-express-checkout).

Создайте [`src/modules/checkout/components/express-checkout/buttons/paypal.tsx`](https://github.com/gorgojs/medusa-integrations/blob/main/examples/payment-paypal/apps/storefront/src/modules/checkout/components/express-checkout/buttons/paypal.tsx) со следующим содержимым:

![Структура проекта Medusa Storefront после создания файла с кнопкой PayPal для экспресс-оплаты](/static/paypal/storefront/src-modules-checkout-components-express-checkout-buttons-paypal.webp)

```tsx title="src/modules/checkout/components/express-checkout/buttons/paypal.tsx" collapsibleLines="1-52"
"use client"

import {
  quoteExpressShipping,
  saveExpressContact,
  startExpressPayment,
} from "@lib/data/express-checkout"
import { getPayPalPayer } from "@lib/data/paypal"
import PayPalScope, {
  isNavigation,
} from "@modules/checkout/components/paypal-scope"
import { PayPalButtons, usePayPalScriptReducer } from "@paypal/react-paypal-js"
import { useEffect, useRef } from "react"
import type { ExpressButtonProps } from "../registry"

/** Rendered by `PayPalButtons` when PayPal is not available to this customer. */
function Unavailable({ onMount }: { onMount: () => void }) {
  useEffect(onMount, [onMount])
  return null
}

const orderIdOf = (data: Record<string, unknown>) => {
  const id = data.paypal_order_id
  if (typeof id !== "string" || !id) {
    throw new Error("PayPal payment session has no order")
  }
  return id
}

function PayPalWalletButton({
  providerId,
  shippingOptionId,
  onUnavailable,
  onError,
  onBusy,
  placeOrder,
  onClosed,
}: ExpressButtonProps) {
  const [{ isResolved, isRejected }] = usePayPalScriptReducer()
  const orderRef = useRef<string | null>(null)

  useEffect(() => {
    if (isRejected) onUnavailable()
  }, [isRejected, onUnavailable])

  if (isRejected) {
    return null
  }
  if (!isResolved) {
    return <div className="h-12 rounded-md bg-ui-bg-component" aria-hidden="true" />
  }

  return (
    <PayPalButtons
      fundingSource="paypal"
      style={{
        layout: "horizontal",
        color: "gold",
        shape: "rect",
        label: "paypal",
        height: 48,
        tagline: false,
        disableMaxWidth: true,
      }}
      createOrder={async () => {
        onError(null)
        const orderId = orderIdOf(
          await startExpressPayment(providerId, { express: true })
        )
        orderRef.current = orderId
        return orderId
      }}
      onShippingAddressChange={async (data, actions) => {
        const orderId = data.orderID || orderRef.current
        if (!orderId) return actions.reject()
        try {
          const quote = await quoteExpressShipping(
            {
              country_code: data.shippingAddress.countryCode ?? "",
              province: data.shippingAddress.state,
              city: data.shippingAddress.city,
              postal_code: data.shippingAddress.postalCode,
            },
            shippingOptionId
          )
          if (!quote.ok) return actions.reject()
          // A new total makes Medusa drop the session, so the order the
          // customer is approving moves to a new one, which patches its amount.
          await startExpressPayment(
            providerId,
            { express: true, paypal_order_id: orderId },
            "paypal_order_id"
          )
        } catch {
          return actions.reject()
        }
      }}
      onApprove={async (data) => {
        onBusy(true)
        try {
          const payer = await getPayPalPayer(data.orderID)
          const approved = payer.amount ? Number(payer.amount.value) : undefined
          const saved = await saveExpressContact(
            {
              email: payer.email,
              phone: payer.phone,
              shipping_address: payer.shipping_address,
            },
            shippingOptionId,
            approved
          )
          if (!saved.ok) {
            onError(
              saved.reason === "totalChanged"
                ? {
                    code: "totalChanged",
                    total: saved.total,
                    currency_code: saved.currency_code,
                  }
                : { code: saved.reason }
            )
            onBusy(false)
            onClosed()
            return
          }
          // The saved address may have changed the total once more.
          await startExpressPayment(
            providerId,
            { express: true, paypal_order_id: data.orderID },
            "paypal_order_id"
          )
          await placeOrder()
        } catch (err) {
          if (isNavigation(err)) return
          onError({ code: "failed", cause: err })
          onBusy(false)
          onClosed()
        }
      }}
      onCancel={() => onClosed()}
      onError={(err) => {
        onError({ code: "failed", cause: err })
        onClosed()
      }}
    >
      <Unavailable onMount={onUnavailable} />
    </PayPalButtons>
  )
}

/**
 * PayPal in the express checkout row. The customer picks the address in the
 * PayPal window, the row answers with the shipping and the new total, and the
 * order is placed once they approve.
 */
export default function PayPalExpressButton(props: ExpressButtonProps) {
  return (
    <PayPalScope
      currencyCode={props.cart.currency_code}
      onUnavailable={props.onUnavailable}
    >
      <PayPalWalletButton {...props} />
    </PayPalScope>
  )
}
```

`createOrder` создаёт платёжную сессию с `express: true`, и провайдер разрешает PayPal спросить адрес. `onShippingAddressChange` пересчитывает доставку и итог для выбранного адреса и создаёт сессию с тем же `paypal_order_id`. Новый итог заставляет Medusa удалить сессию, поэтому провайдер привязывает прежний заказ PayPal к новой сессии и обновляет его сумму. `onApprove` сохраняет в корзине контакты и адрес покупателя из `getPayPalPayer`, сравнивает итог с одобренной суммой и оформляет заказ. Если итог выше одобренной суммы, кнопка останавливается с сообщением, потому что PayPal не всегда сообщает адрес до одобрения, например при гостевой оплате картой, и доставка для него может поднять итог.

Затем добавьте кнопку в [`src/modules/checkout/components/express-checkout/registry.ts`](https://github.com/gorgojs/medusa-integrations/blob/main/examples/payment-paypal/apps/storefront/src/modules/checkout/components/express-checkout/registry.ts#L43-L48):

![Структура проекта Medusa Storefront после обновления реестра экспресс-оплаты](/static/paypal/storefront/src-modules-checkout-components-express-checkout-registry.webp)


Теперь ряд показывает PayPal в каждом регионе, где включён `pp_paypal_paypal`, и прячет кнопку, если PayPal недоступен покупателю.

# {frontmatter.title}

В этом руководстве вы узнаете, как просматривать и редактировать параметры интеграции PayPal в Medusa Admin через [модуль интеграций](/medusa-modules/integration).

## Просмотр данных PayPal

Чтобы открыть страницу с настройками PayPal:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → PayPal**.

Откроется страница настроек PayPal, где можно просматривать параметры доступа PayPal, поведение оплаты и настройки страницы оплаты PayPal.

![Общий вид настроек PayPal](/static/paypal/ru/settings-overview.webp)

---

## Редактирование параметров доступа PayPal

В первой секции страницы можно изменить окружение, Client ID, секретный ключ и ID вебхука. **Sandbox** принимает тестовые платежи с sandbox-аккаунтов, **Live** принимает настоящие, и у каждого окружения в <a href="https://developer.paypal.com/dashboard/" target="_blank">PayPal Developer Dashboard</a> свои ключи и вебхуки.

Чтобы отредактировать параметры доступа:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Доступы** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените окружение, Client ID, секретный ключ и ID вебхука. Откуда берётся ID вебхука, описано в разделе [Настройка вебхуков](/medusa-integrations/paypal/getting-started#настройка-вебхуков).
5. Нажмите **Сохранить**.

![Редактирование параметров доступа PayPal](/static/paypal/ru/edit-credential.webp)

Затем нажмите **Проверить соединение**. Кнопка получает токен доступа в выбранном окружении, поэтому неверные ключи или ключи другого окружения не пройдут проверку. Если задан ID вебхука, она дополнительно проверяет, что вебхук есть в этом окружении и подписан на `PAYMENT.AUTHORIZATION.CREATED` и `PAYMENT.CAPTURE.COMPLETED`.

## Редактирование поведения оплаты

Секция **Поведение** определяет тип поведения платежей.

Если выбрано **Списать сразу**, используется одностадийная оплата. Если выбрано **Только заблокировать**, используется двухстадийная оплата, и заблокированную сумму вы списываете из заказа в Medusa Admin. PayPal гарантирует средства 3 дня и позволяет списать их в течение 29 дней.

Чтобы изменить поведение оплаты:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Поведение** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените способ списания.
5. Нажмите **Сохранить**.

![Редактирование поведения оплаты](/static/paypal/ru/edit-behavior.webp)

## Редактирование страницы оплаты PayPal

Секция **Страница оплаты PayPal** определяет, что покупатель видит после перехода в PayPal.

- **Название бренда** заменяет на страницах PayPal название компании из вашего аккаунта PayPal, до 127 символов.
- **Стартовая страница** определяет, что покупатель видит сначала. Её можно оставить на выбор PayPal или открыть вход в PayPal либо гостевую оплату картой.
- **Текст в выписке по карте** добавляется после названия вашей компании в выписке по карте покупателя. В выписке видно 22 символа вместе с префиксом `PAYPAL *`, поэтому текст должен быть коротким.
- **Товары корзины** передаёт в PayPal товары, доставку, налог и скидку из корзины. Покупатель видит их в окне PayPal, вы видите их в транзакции в аккаунте PayPal. Если корзина не совпадает с суммой платежа, например при оплате подарочной картой, заказ уходит в PayPal только с суммой.

Чтобы отредактировать настройки страницы оплаты:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Страница оплаты PayPal** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените название бренда, стартовую страницу, текст в выписке по карте и переключатель товаров корзины.
5. Нажмите **Сохранить**.

![Редактирование страницы оплаты PayPal](/static/paypal/ru/edit-checkout.webp)

## Добавление платёжного провайдера

Чтобы добавить отображаемый в витрине магазина платёжный провайдер PayPal:

1. Перейдите в **Настройки → Регионы**.
2. Выберите ваш регион.
3. В первой секции нажмите на меню действий в заголовке секции.
4. Выберите **Редактировать**.
5. В открывшемся модальном окне добавьте **Paypal (PAYPAL)** в платёжные провайдеры.
6. Нажмите **Сохранить**.

![Добавление платёжного провайдера](/static/paypal/ru/add-payment-provider.webp)

Плагин отказывает в оплате в валюте, которую PayPal не принимает, поэтому добавляйте PayPal только в регионы с одной из <a href="https://developer.paypal.com/reference/currency-codes/" target="_blank">25 валют PayPal</a>. BRL, CNY и MYR PayPal принимает как валюту платежа только для аккаунтов PayPal из той же страны.

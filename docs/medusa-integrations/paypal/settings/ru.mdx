В этом руководстве вы узнаете, как просматривать и изменять настройки интеграции PayPal в Medusa Admin через [Модуль интеграций](/medusa-modules/integration).

## Просмотр данных PayPal

Чтобы посмотреть данные PayPal:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → PayPal**.

Откроется страница настроек PayPal, где видны доступы, поведение платежей и настройки страницы оплаты PayPal.

## Редактирование доступов PayPal

В секции **Доступы** хранятся окружение и ключи вашего приложения из <a href="https://developer.paypal.com/dashboard/" target="_blank">PayPal Developer Dashboard</a>. **Sandbox** принимает тестовые платежи с sandbox-аккаунтов, **Live** принимает настоящие, и у каждого окружения свои Client ID, секрет и вебхуки.

Чтобы изменить доступы:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Доступы** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели выберите окружение и обновите Client ID, секрет и ID вебхука. Откуда берётся ID вебхука, описано в разделе [Настройка вебхуков](/medusa-integrations/paypal/getting-started#настройка-вебхуков).
5. Нажмите **Сохранить**.

{/* TODO: screenshot edit-credentials */}

Затем нажмите **Проверить соединение**. Кнопка получает токен доступа в выбранном окружении, поэтому неверные ключи или ключи другого окружения не пройдут проверку. Если задан ID вебхука, она дополнительно проверяет, что вебхук есть в этом окружении и подписан на `PAYMENT.AUTHORIZATION.CREATED` и `PAYMENT.CAPTURE.COMPLETED`.

## Редактирование поведения платежей

Секция **Поведение** определяет, когда PayPal списывает деньги.

- **Списать сразу** списывает деньги, когда покупатель платит.
- **Только заблокировать** блокирует сумму, а списываете её вы из заказа в Medusa Admin. PayPal гарантирует средства 3 дня и позволяет списать их в течение 29 дней.

Чтобы изменить поведение платежей:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Поведение** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели выберите способ списания.
5. Нажмите **Сохранить**.

{/* TODO: screenshot edit-behavior */}

<Note type="warning" title="Списания и возвраты">Списание из заказа в Medusa Admin всегда забирает всю заблокированную сумму, даже если вы укажете меньшую. Возвраты бывают частичными, и делать их тоже нужно из заказа в Medusa Admin, потому что возврат из кабинета PayPal в Medusa не попадает.</Note>

## Редактирование страницы оплаты PayPal

Секция **Страница оплаты PayPal** меняет то, что покупатель видит после перехода в PayPal.

- **Название бренда** заменяет на страницах PayPal название компании из вашего аккаунта PayPal, до 127 символов.
- **Стартовая страница** определяет, что покупатель видит сначала. Её можно оставить на выбор PayPal или открыть вход в PayPal либо гостевую оплату картой.
- **Текст в выписке по карте** добавляется после названия вашей компании в выписке по карте покупателя. В выписке видно 22 символа вместе с префиксом `PAYPAL *`, поэтому текст должен быть коротким.

Чтобы изменить настройки страницы оплаты:

1. Перейдите в **Настройки → Интеграции → PayPal**.
2. В секции **Страница оплаты PayPal** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели обновите название бренда, стартовую страницу и текст в выписке по карте.
5. Нажмите **Сохранить**.

## Добавление платёжного провайдера

Чтобы предложить PayPal в регионе витрины:

1. Перейдите в **Настройки → Регионы**.
2. Выберите свой регион.
3. В первой секции нажмите на меню действий в заголовке секции.
4. Выберите **Редактировать**.
5. В открывшемся окне добавьте провайдер PayPal, `pp_paypal_paypal`, в платёжные провайдеры.
6. Нажмите **Сохранить**.

{/* TODO: screenshot add-payment-provider */}

Плагин отказывает в оплате в валюте, которую PayPal не принимает, поэтому добавляйте PayPal только в регионы с одной из <a href="https://developer.paypal.com/reference/currency-codes/" target="_blank">25 валют PayPal</a>. BRL, CNY и MYR PayPal принимает как валюту платежа только для аккаунтов PayPal из той же страны.

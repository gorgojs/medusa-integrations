# {frontmatter.title}

Бесплатный плагин интеграции, который импортирует товары, категории и цены из ERP 1С:Предприятие в Medusa по протоколу CommerceML. Остатки и заказы передаёт платная версия 1С:Предприятие, у неё [своя документация](/medusa-integrations/1c-enterprise).

<Note type="success" title="Платная версия проходит закрытое бета-тестирование">Участники получают цену ниже релизной на первый год, разбор граничных случаев своей конфигурации 1С и чат с командой разработки. Чтобы присоединиться к тестированию, [оставьте заявку](https://gorgojs.ru/beta/medusa-1c).</Note>

---

## Возможности бесплатной и платной версии

| Возможности | Бесплатная | Платная |
|---|---|---|
| Обмен по CommerceML | ✓ | ✓ |
| Товары и категории из 1С в Medusa | ✓ | ✓ |
| Предложения из 1С, варианты с артикулами и ценами | ✓ | ✓ |
| Настройка плагина в Medusa Admin через [Модуль интеграций](/medusa-modules/integration) <AccentBadge badge="New" /> | ✓ | ✓ |
| Типы цен 1С как прайс-листы Medusa | – | ✓ |
| Остатки в разрезе складов | – | ✓ |
| Обмен заказами в обе стороны | – | ✓ |
| Оптимизация под большие каталоги | – | ✓ |

<Note type="default" title="Что такое Модуль интеграций?">Модуль интеграций позволяет любому плагину описывать свои параметры в виде схемы и даёт администратору магазина настраивать их в Medusa Admin, без правок `medusa-config` и без повторного развёртывания. UI, хранение, шифрование и валидацию модуль берёт на себя. Читайте подробнее в [этой документации](/medusa-modules/integration).</Note>

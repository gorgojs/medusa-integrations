# {frontmatter.title}

В этом руководстве вы узнаете, как управлять настройками интеграции 1С:Предприятие Pro.

## Просмотр настроек 1С:Предприятие

Чтобы открыть страницу с настройками 1С:Предприятие:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.

Откроется страница настроек интеграции. На ней показаны статус, секции **Настройки синхронизации** и **Дополнительно** и две секции плагина, **Канал продаж и регион** и **Соответствие валют**.

![Общий вид настроек 1С:Предприятие Pro](/static/1c-pro/ru/settings-overview.webp)

## Выбор канала продаж и региона

Канал продаж и регион обязательны. Пока они не сохранены, интеграция остаётся в статусе **Не настроено** или **Не завершено**, и обмен отвечает 1С отказом.

- **Канал продаж** – к нему плагин привязывает товары и склады из 1С. Его же получают заказы, пришедшие из 1С.
- **Регион** – регион заказа из 1С, если регион не нашёлся по валюте документа.

Чтобы выбрать канал продаж и регион:

1. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.
2. В секции **Канал продаж и регион** выберите канал продаж.
3. Выберите регион.
4. Нажмите **Сохранить**.

![Выбор канала продаж и региона](/static/1c-pro/ru/sales-channel-region.webp)

## Редактирование настроек синхронизации

Секция **Настройки синхронизации** содержит поле **ID типа цены**. Это `Ид` типа цен 1С, который плагин записывает в цену варианта как розничную. Если поле пустое, розничным считается первый тип цен в `offers.xml`. Каждый из остальных типов становится прайс-листом, подробнее в разделе [Включение прайс-листов из 1С](#включение-прайс-листов-из-1с) ниже.

При выгрузке каталога в 1С плагин указывает у цен этот же `Ид`. Если поле пустое, в выгрузку уходит `Ид` `11111111-1111-1111-1111-111111111111`.

Чтобы изменить настройки синхронизации:

1. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.
2. В секции **Настройки синхронизации** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели укажите `Ид` розничного типа цен.
5. Нажмите **Сохранить**.

![Редактирование настроек синхронизации](/static/1c-pro/ru/edit-sync-settings.webp)

## Настройка соответствия валют

Секция **Соответствие валют** связывает название валюты, как его пишет 1С в файлах обмена, с валютой магазина Medusa. По нему плагин определяет валюту цен вариантов, цен прайс-листов и заказов из 1С, а по валюте заказа выбирает его регион.

Название сравнивается без учёта регистра и пробелов по краям. Для валюты без соответствия плагин берёт её название из 1С в нижнем регистре как код валюты Medusa, поэтому `USD` из 1С становится `usd` и без настройки. Если соответствие не задано вовсе, плагин считает `руб` валютой `rub`.

Чтобы добавить соответствие:

1. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.
2. В секции **Соответствие валют** нажмите **Добавить**.
3. В открывшейся боковой панели выберите валюту Medusa из валют магазина.
4. Введите название валюты, как его пишет 1С.
5. Нажмите **Сохранить**.

Чтобы изменить или удалить соответствие, откройте меню действий в его строке и выберите **Редактировать** или **Удалить**.

![Добавление соответствия валюты](/static/1c-pro/ru/add-currency-mapping.webp)

## Редактирование дополнительных настроек

Секция **Дополнительно** содержит два поля:

- **Префикс номера заказа** – строка перед номером заказа Medusa в выгрузке в 1С. С префиксом `WEB-` заказ 1042 уходит в 1С под номером `WEB-1042`.
- **Действие для товаров, пропавших из полной выгрузки каталога** – что делать с ранее импортированным товаром, которого больше нет в полной выгрузке каталога. **Ничего не делать**, **Деактивировать (в черновик)** или **Удалить**. По умолчанию **Ничего не делать**.

Номер, под которым заказ ушёл в 1С, плагин сохраняет в самом заказе. Когда 1С присылает заказ обратно, плагин узнаёт его по `Ид` или по этому номеру и второй раз не создаёт, поэтому смена префикса уже выгруженные заказы не задевает.

Действие срабатывает только после полной выгрузки каталога. Если 1С прислала только изменения, пропавшими товары не считаются.

Чтобы изменить дополнительные настройки:

1. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.
2. В секции **Дополнительно** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели задайте префикс и действие для пропавших товаров.
5. Нажмите **Сохранить**.

![Редактирование дополнительных настроек](/static/1c-pro/ru/edit-advanced-settings.webp)

## Проверка настроек

Проверка соединения у этого плагина не обращается к 1С, потому что обмен запускает сама 1С. Вместо этого она проверяет, что канал продаж и регион выбраны и их ID похожи на настоящие, `sc_…` и `reg_…`.

Чтобы проверить настройки:

1. Перейдите в **Настройки → Интеграции → 1С:Предприятие**.
2. Откройте меню действий у названия интеграции.
3. Выберите **Проверить соединение**.

Результат проверки появится в уведомлении.

## Включение прайс-листов из 1С

Каждый тип цен 1С, кроме розничного, плагин переносит в Medusa прайс-листом. Новый прайс-лист он создаёт черновиком с типом **Распродажа**, названием типа цен и описанием `1C price type: <название>`. Цены в нём обновляются при каждом обмене. Название, статус, тип и правила существующего прайс-листа плагин не трогает, поэтому ваши изменения в нём сохраняются.

Чтобы цены прайс-листа увидели покупатели:

1. Откройте Medusa Admin и перейдите в **Прайс-листы**.
2. Откройте прайс-лист с названием типа цен 1С.
3. В секции **Конфигурация** нажмите на меню действий, выберите **Редактировать**, укажите в поле **Доступность для клиентов** группы покупателей и нажмите **Сохранить**.
4. В заголовке прайс-листа нажмите на меню действий и выберите **Редактировать**.
5. Смените **Статус** на **Активный** и нажмите **Сохранить**.

Группы стоит указать до включения. Иначе между шагами прайс-лист будет действовать для всех.

<Note type="warning">

Активный прайс-лист без групп покупателей Medusa применяет ко всем посетителям витрины, включая гостей. Если оптовая цена ниже розничной, такой прайс-лист покажет её каждому. Поэтому плагин и создаёт новые прайс-листы черновиками.

</Note>

Чтобы прайс-лист сразу получал группу и статус без ручной настройки, используйте хук `setPriceLists`. Как это сделать, показывает пример [Оптовая цена для группы покупателей](/medusa-integrations/1c-pro/hooks/examples#оптовая-цена-для-группы-покупателей).

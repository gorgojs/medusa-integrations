# {frontmatter.title}

In this guide, you'll learn how to view and edit YooKassa integration settings in Medusa Admin via the [Integration Module](/medusa-modules/integration).

## View YooKassa Details

To view the YooKassa details:

1. Open Medusa Admin.
2. Go to **Settings → Integrations → YooKassa**.

This opens the YooKassa settings page where you can review the credential details, receipt generation and behavior payment parameters.

![YooKassa settings overview](/static/yookassa/en/settings-overview.png)

---

## Edit YooKassa Credential Parameters

You can update the Terminal key and Password from the first section on the YooKassa settings page.

To edit the credential parameters:

1. Go to **Settings → Integrations → YooKassa**.
2. In the **Credentials** section, click the action menu in the section's header.
3. Choose **Edit**.
4. In the side panel that opens, update Shop ID and Secret Key.
5. Click **Save**.

![Edit YooKassa credential details](/static/yookassa/en/edit-credential.png)

---

## Edit Receipt Generation Details

The **Receipt** section stores the receipt generation according to Russian fiscal data format (FFD).

To edit the receipt details:

1. Go to **Settings → Integrations → YooKassa**.
2. In the **Receipt** section, click the action menu in the section's header.
3. Choose **Edit**.
4. In the side panel that opens, enable or disable Atol Online FFD 1.2 sales register, update tax system code, default VAT rates for products and shipping.
5. Click **Save**.

![Edit receipt details](/static/yookassa/en/edit-receipt.png)

---

## Edit Behavior Type

The **Behavior** section determines the payments processing type.

If auto-capture is enabled, one-step payment is used. If it's disabled, two-step payment is used.

To edit the payment and VAT settings:

1. Go to **Settings → Integrations → YooKassa**.
2. In the **Behavior** section, click the action menu in the section's header.
3. Choose **Edit**.
4. In the side panel that opens, update the auto-capture payment type and default payment description.
5. Click **Save**.

![Edit behavior tsype](/static/yookassa/en/edit-behavior.png)

---

## Add Payment Provider

To add a payment providers displayed in the Storefront for YooKassa:

1. Go to **Settings → Regions**.
2. Choose your region.
3. In the first section, click the action menu in the section's header.
4. Choose **Edit**.
5. In the modal that opens:
![Add payment provider](/static/yookassa/en/add-payment-provider.png)
   - Add **YooKassa** to Payment Providers.
6. Click **Save**.

# {frontmatter.title}

В этом руководстве вы узнаете, как просматривать и редактировать параметры интеграции ЮKassa в Medusa Admin через [модуль интеграций](/medusa-modules/integration).

## Просмотр данных ЮKassa

Чтобы открыть страницу с настройками ЮKassa:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → ЮKassa**.

Откроется страница настроек ЮKassa, где можно просматривать параметры доступа ЮKassa, параметры формирования чеков и поведения оплаты.

![Общий вид настроек ЮKassa](/static/yookassa/ru/settings-overview.png)

---

## Редактирование параметров доступа ЮKassa

В первой секции страницы можно изменить ключ терминала и пароль.

Чтобы отредактировать параметры доступа:

1. Перейдите в **Настройки → Интеграции → ЮKassa**.
2. Нажмите на меню действий в заголовке секции **Доступы**.
3. Выберите **Редактировать**.
4. Измените идентификатор магазина и секретный ключ в открывшейся боковой панели.
5. Нажмите **Сохранить**.

![Редактирование параметры доступа](/static/yookassa/ru/edit-credential.png)

---

## Редактирование параметов формирования чеков

Секция **Чеки** хранит данные для формирование онлайн-чеков по 54-ФЗ.

Чтобы отредактировать параметры формирования чеков:

1. Перейдите в **Настройки → Интеграции → ЮKassa**.
2. Нажмите на меню действий в заголовке секции **Чеки**.
3. Выберите **Редактировать**.
4. Обновите соотетсвующий параметр если вы используете онлайн-кассу Атол Онлайн с ФФД 1.2, систему налогообложения, cтавки НДС по умолчанию для товаров и доставки в открывшейся боковой панели.
5. Нажмите **Сохранить**.

![Редактирование параметов чеков](/static/yookassa/ru/edit-receipt.png)

---

## Редактирование поведения оплаты

Секция **Поведение** определяет тип поведения платежей.

Если включено автосписание платеж, используется одностадийная оплата. Если оно выключено, то двухстадийная оплата.

Чтобы изменить поведение оплаты:

1. Перейдите в **Настройки → Интеграции → ЮKassa**.
2. Нажмите на меню действий в заголовке секции **Поведение**.
3. Выберите **Редактировать**.
4. Измените настройку автосписания и описание платежа по умолчанию в открывшейся боковой панели.
5. Нажмите **Сохранить**.

![Редактирование поведения оплаты](/static/yookassa/ru/edit-behavior.png)

## Добавление платежного провайдера

Чтобы добавить отображаемый в витрине магазина платежного провайдера ЮKassa:

1. Перейдите в **Настройки → Регионы**.
2. Выберите ваш регион.
3. Нажмите на меню действий в заголовке секции в первой секции.
4. Выберите **Редактировать**.
5. Добавьте **YooKassa** в платежные провайдеры в открывшемся модальном окне.
6. Нажмите **Сохранить**.

![Добавление платежного провайдера](/static/yookassa/ru/add-payment-provider.png)

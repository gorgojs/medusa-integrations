# {frontmatter.title}

A paid Medusa plugin for data exchange with 1C:Enterprise ERP over the CommerceML protocol. The free version, 1C:Enterprise Catalog, only imports the catalog and prices. It's described in [separate documentation](/medusa-integrations/1c-enterprise-catalog).

<Note type="success" title="The plugin is in closed beta">

Participants get a price below the release one for the first year, help with the specifics of their own 1C configuration and a chat with the development team. To take part in the testing, [apply for the beta](https://gorgojs.com/beta/medusa-1c).

</Note>

---

## Plugin Features

- **CommerceML Exchange:** Works with the standard site exchange that 1C starts itself.
- **Catalog from 1C:** Products, categories from classifier groups, product types and images.
- **Variants and Retail Prices:** Variants built from 1C characteristics with the article as the SKU, their options, and the retail price from the offers.
- **Price Types as Price Lists:** Every non-retail 1C price type becomes a Medusa price list.
- **Per-Warehouse Stock:** 1C warehouses become Medusa stock locations, with stock levels tracked for each of them.
- **Two-Way Order Exchange:** Medusa orders go to 1C, and orders created in 1C appear in Medusa.
- **Catalog Export to 1C:** Products created or changed in Medusa go to 1C.
- **Products Missing from 1C:** After a full catalog export, the plugin can unpublish or delete them.
- **Large Catalogs:** Tested on a 400,000 SKU catalog, which the plugin processes in batches of 100 products.
- **Workflow Hooks:** Your own code changes what the exchange writes to Medusa and sends to 1C, without forking the plugin.
- **Test Coverage:** Unit, integration and load tests of the CommerceML exchange.
- **Detailed Logging:** Progress of every batch and failure reasons in the Medusa log, with import step durations at the `debug` level.
- **[Integration Module](/medusa-modules/integration)**<AccentBadge badge="New" />: Configure this plugin directly in the Medusa Admin application, with no configuration files to edit and no store redeploy.

<Note type="default" title="What Is the Integration Module?">

The Integration Module lets any plugin declare its options as a schema, so a store administrator can configure them in the Medusa Admin, with no `medusa-config` edits and no redeploy. The module takes care of the UI, storage, encryption and validation. Read more in [this documentation](/medusa-modules/integration).

</Note>

## What Is 1C:Enterprise

1C:Enterprise is a platform that accounting systems such as "1C:Trade Management" are built on. These systems exchange CommerceML files with an online store. 1C always starts the exchange itself. It calls the store's exchange URL, sends the catalog, offers and orders, and picks up the orders placed on the store. Learn more at the <a href="https://1ci.com/" target="_blank">1C website</a>.

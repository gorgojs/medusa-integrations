# {frontmatter.title}

В этом руководстве вы узнаете, как установить и настроить платёжный провайдер Mollie для Medusa, подготовить аккаунт Mollie и подключить вебхук.

## Требования

- Medusa v2.17.2 или новее
- Node.js v22.23.4, v24.22.1, v26.12.1 или новее
- Аккаунт Mollie с профилем сайта. Для тестов подойдёт тестовый API-ключ профиля, для настоящих платежей нужен его live-ключ
- [Модуль интеграций](/medusa-modules/integration)

---

<CodeTabs>
  <CodeTab label="yarn" value="yarn">

## Настройка

Добавьте конфигурацию провайдера Модуля интеграций и Платёжного модуля Medusa в файл `medusa-config.ts` приложения Medusa Admin:

```ts title="medusa-config.ts"
// ...
const MOLLIE_INTEGRATION_ID = "mollie-1"

module.exports = defineConfig({
  // ...
  plugins: [
    // ...
    {
      resolve: "@gorgo/medusa-integration",
      options: {
        encryptionKey: process.env.INTEGRATION_ENCRYPTION_KEY,
        providers: [
          {
            resolve: "@gorgo/medusa-payment-mollie/providers/integration-mollie",
            id: MOLLIE_INTEGRATION_ID,
            options: {},
          },
        ],
      },
    },
    {
      resolve: "@gorgo/medusa-payment-mollie",
      options: {},
    },
  ],
  modules: [
    // ...
    {
      resolve: "@medusajs/medusa/payment",
      options: {
        providers: [
          {
            resolve: "@gorgo/medusa-payment-mollie/providers/payment-mollie",
            id: "mollie",
            options: {
              id: MOLLIE_INTEGRATION_ID
            }
          },
        ],
      },
    },
  ],
})
```

Платёжный провайдер, зарегистрированный так, получает id `pp_mollie_mollie` и принимает вебхуки на роуте `/hooks/payment/mollie_mollie`.

Добавьте переменную окружения с секретным ключом шифрования:

```text title=".env"
INTEGRATION_ENCRYPTION_KEY=supersecret
```

## Подготовка аккаунта

У каждого профиля сайта в аккаунте Mollie два API-ключа. Тестовый начинается с `test_` и работает в тестовом режиме, live-ключ начинается с `live_` и создаёт настоящие платежи. Скопируйте нужный ключ в разделе **Developers → API keys** в <a href="https://my.mollie.com/" target="_blank">Mollie Web App</a>, выбрав профиль сайта вашего магазина.

Покупатель платит на платёжной странице Mollie и видит там только способы оплаты, включённые в профиле. Включите нужные способы в Mollie Web App. В тестовом режиме способ работает сразу после включения, даже если Mollie ещё показывает его на проверке.

Тестовый режим принимает только EUR. Для тестов добавьте провайдер в регион с евро, как описано в разделе [Добавление платёжного провайдера](/medusa-integrations/mollie/settings#добавление-платёжного-провайдера). В live-режиме набор способов оплаты, доступных покупателю, зависит от валюты корзины.

## Настройка вебхуков

Mollie вызывает вебхук при каждом изменении платежа. Адрес вебхука плагин передаёт с каждым созданным платежом, поэтому регистрировать что-либо в Mollie не нужно. Укажите адрес в поле **Адрес вебхука** настроек Mollie в Medusa Admin в следующем формате:

```text title="Webhook URL"
https://{YOUR_MEDUSA_DOMAIN}/hooks/payment/mollie_mollie
```

Замените `{YOUR_MEDUSA_DOMAIN}` на домен вашего магазина Medusa. Настройки принимают только адрес на `https://`, в пути которого есть `/hooks/payment/mollie_`.

Вебхук Mollie содержит только ID платежа и не подписан. Плагин перечитывает платёж в Mollie вашим API-ключом и действует только по ответу Mollie, поэтому поддельное уведомление заказ не изменит. Когда платёж оплачен, плагин создаёт заказ, даже если покупатель закрыл вкладку на платёжной странице Mollie. Уведомление о платеже, которого нет в вашем аккаунте, плагин пропускает.

Открытый платёж, в котором покупатель ещё не выбрал способ оплаты, Mollie не отменяет. Поэтому платёж, чья сессия в Medusa была заменена, остаётся доступным для оплаты на странице Mollie, пока не истечёт. Если покупатель всё же его оплатит, заказ для него создать нельзя, и плагин возвращает платёж целиком и пишет предупреждение в лог. Заблокированную сумму такой сессии плагин вместо возврата разблокирует.

Mollie <a href="https://docs.mollie.com/reference/webhooks" target="_blank">повторяет неудачную доставку</a> до 10 раз в течение примерно 26 часов. Адрес на `localhost` Mollie не принимает. На время разработки запускайте бэкенд за туннелем с публичным HTTPS-адресом, как это делает пример проекта командой `yarn dev:tunnel`.

<Note type="warning">Не трогайте раздел **Developers → Webhooks** в Mollie Web App. В нём настраиваются вебхуки нового поколения (next-gen), а этот плагин их не использует. Уведомления о платежах приходят плагину на адрес, который он передаёт с каждым платежом.</Note>

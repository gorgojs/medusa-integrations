# {frontmatter.title}

In this guide, you'll learn how to install and configure the ApiShip plugin for Medusa.

## Requirements

- Medusa v2.17.2 or later
- Node.js 20.19 or later, or 22.12 or later
- An ApiShip account - [sign in or create one](https://a.apiship.ru)
- [Integration Module](/medusa-modules/integration)

---

## Installation

<CodeTabs>
  <CodeTab label="yarn" value="yarn">
    ```bash
    yarn add @gorgo/medusa-integration @gorgo/medusa-fulfillment-apiship
    ```
  </CodeTab>
  <CodeTab label="npm" value="npm">
    ```bash
    npm install @gorgo/medusa-integration @gorgo/medusa-fulfillment-apiship
    ```
  </CodeTab>
</CodeTabs>

## Configuration

Register the plugin and its two providers in `medusa-config.ts` of your Medusa application:

```ts title="medusa-config.ts"
// ...
const APISHIP_INTEGRATION_ID = "apiship-1"

module.exports = defineConfig({
  // ...
  plugins: [
    // ...
    {
      resolve: "@gorgo/medusa-integration",
      options: {
        encryptionKey: process.env.INTEGRATION_ENCRYPTION_KEY,
        providers: [
          {
            resolve: "@gorgo/medusa-fulfillment-apiship/providers/integration-apiship",
            id: APISHIP_INTEGRATION_ID,
            options: {},
          },
        ],
      },
    },
    {
      resolve: "@gorgo/medusa-fulfillment-apiship",
      options: {},
    },
  ],
  modules: [
    // ...
    {
      resolve: "@medusajs/medusa/fulfillment",
      options: {
        providers: [
          {
            resolve: "@medusajs/medusa/fulfillment-manual",
            id: "manual",
          },
          {
            resolve: "@gorgo/medusa-fulfillment-apiship/providers/fulfillment-apiship",
            id: "apiship",
            options: {
              id: APISHIP_INTEGRATION_ID,
            },
          },
        ],
      },
    },
  ],
})
```

The configuration registers three things:

- The integration provider under `@gorgo/medusa-integration`. Its `id`, `apiship-1`, names the instance, so its settings live under `int_apiship_apiship-1` and open in Medusa Admin at **Settings → Integrations → ApiShip**.
- The plugin itself. Without this entry the provider still works, but Medusa Admin doesn't load the plugin's settings page, its delivery services widget and its translations.
- The fulfillment provider under `@medusajs/medusa/fulfillment`. Its `options.id` must match the integration provider's `id`, which is how it finds its settings. Shipping options you create with it get the provider `apiship_apiship`.

Listing providers for `@medusajs/medusa/fulfillment` replaces Medusa's default list, so the configuration names the manual provider again. Without it, shipping options that use `manual_manual` stop working.

Add the encryption key the Integration Module encrypts the API token with to your environment variables:

```text title=".env"
INTEGRATION_ENCRYPTION_KEY=supersecret
```

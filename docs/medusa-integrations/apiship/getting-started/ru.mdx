# {frontmatter.title}

В этом руководстве вы узнаете, как установить и настроить плагин ApiShip для Medusa.

## Требования

- Medusa v2.17.2 или новее
- Node.js 20.19 или новее либо 22.12 или новее
- Аккаунт ApiShip – [зарегистрируйтесь или войдите](https://a.apiship.ru)
- [Модуль интеграций](/medusa-modules/integration)

---

## Установка

<CodeTabs>
  <CodeTab label="yarn" value="yarn">
    ```bash
    yarn add @gorgo/medusa-integration @gorgo/medusa-fulfillment-apiship
    ```
  </CodeTab>
  <CodeTab label="npm" value="npm">
    ```bash
    npm install @gorgo/medusa-integration @gorgo/medusa-fulfillment-apiship
    ```
  </CodeTab>
</CodeTabs>

## Настройка

Зарегистрируйте плагин и два его провайдера в `medusa-config.ts` вашего приложения Medusa:

```ts title="medusa-config.ts"
// ...
const APISHIP_INTEGRATION_ID = "apiship-1"

module.exports = defineConfig({
  // ...
  plugins: [
    // ...
    {
      resolve: "@gorgo/medusa-integration",
      options: {
        encryptionKey: process.env.INTEGRATION_ENCRYPTION_KEY,
        providers: [
          {
            resolve: "@gorgo/medusa-fulfillment-apiship/providers/integration-apiship",
            id: APISHIP_INTEGRATION_ID,
            options: {},
          },
        ],
      },
    },
    {
      resolve: "@gorgo/medusa-fulfillment-apiship",
      options: {},
    },
  ],
  modules: [
    // ...
    {
      resolve: "@medusajs/medusa/fulfillment",
      options: {
        providers: [
          {
            resolve: "@medusajs/medusa/fulfillment-manual",
            id: "manual",
          },
          {
            resolve: "@gorgo/medusa-fulfillment-apiship/providers/fulfillment-apiship",
            id: "apiship",
            options: {
              id: APISHIP_INTEGRATION_ID,
            },
          },
        ],
      },
    },
  ],
})
```

Конфигурация регистрирует три вещи:

- Провайдер интеграции в `@gorgo/medusa-integration`. Его `id`, `apiship-1`, задаёт имя инстанса, поэтому его настройки хранятся под `int_apiship_apiship-1` и открываются в Medusa Admin в **Настройки → Интеграции → ApiShip**.
- Сам плагин. Без этой записи провайдер продолжает работать, но Medusa Admin не загружает страницу настроек плагина, виджет служб доставки и переводы.
- Провайдер фулфилмента в `@medusajs/medusa/fulfillment`. Его `options.id` должен совпадать с `id` провайдера интеграции, так он находит свои настройки. Способы доставки, которые вы с ним создаёте, получают провайдер `apiship_apiship`.

Список провайдеров в `@medusajs/medusa/fulfillment` заменяет список Medusa по умолчанию, поэтому конфигурация заново указывает ручной провайдер. Без него перестают работать способы доставки с `manual_manual`.

Добавьте в переменные окружения ключ, которым Модуль интеграций шифрует API-токен:

```text title=".env"
INTEGRATION_ENCRYPTION_KEY=supersecret
```

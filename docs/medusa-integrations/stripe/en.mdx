# {frontmatter.title}

A Medusa plugin that provides Stripe payments. It replaces Medusa's built-in Stripe provider under the same provider ID, so the payments the built-in provider created keep being captured and refunded after the switch.

## Plugin Features

- **One-Step & Two-Step Payments:** Automatic capture, or authorization with a hold you capture from the order.
- **Payment Methods from Your Stripe Account:** Cards, wallets and local methods such as iDEAL or Bancontact, as enabled in the Stripe Dashboard or in a payment method configuration.
- **Express Checkout:** Apple Pay, Google Pay and Link in the express checkout row of the [Medusa DTC Starter by Gorgo](/tools/medusa-dtc-starter), with the shipping recalculated for the address the customer picks in the wallet.
- **Deferred PaymentIntent:** The PaymentIntent is created when the customer pays, with the final amount and the delivery address from the cart.
- **Refunds & Cancellations:** Partial refunds and cancellation of authorized payments.
- **Webhook Notifications:** Signed Stripe events complete an order when the customer leaves before the storefront places it.
- **Saved Cards:** A Stripe customer for each registered customer, and their saved payment methods.
- **Drop-In Replacement:** The same `pp_stripe_stripe` provider and webhook URL as Medusa's `@medusajs/payment-stripe`.
- **Tested:** Unit tests for every provider method and integration tests for the whole payment cycle on Medusa.
- **Storefront Example:** A complete <a href="https://github.com/gorgojs/medusa-integrations/tree/main/examples/payment-stripe/apps/storefront" target="_blank">Next.js storefront</a> ready to use as a reference.
- **[Integration module](/medusa-modules/integration)**<AccentBadge badge="New" />: Configure this plugin directly in the Medusa Admin application – no editing configuration files or redeploying the store.

<Note type="default" title="What Is the Integration Module?">The Integration module lets any plugin declare its options as a schema, so a store administrator can configure them in the Medusa Admin, with no `medusa-config` edits and no redeploy. The module takes care of the UI, storage, encryption and validation. Read more in [this documentation](/medusa-modules/integration).</Note>

## What Is Stripe

Stripe is a payment platform for online businesses. It accepts cards, wallets such as Apple Pay and Google Pay, and local payment methods in <a href="https://docs.stripe.com/currencies" target="_blank">more than 130 currencies</a>. Learn more at the <a href="https://stripe.com/" target="_blank">Stripe website</a>.

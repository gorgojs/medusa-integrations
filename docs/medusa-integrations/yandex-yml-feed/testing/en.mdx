# {frontmatter.title}

To run tests, navigate to the [`integration-tests/feed-yandex`](https://github.com/gorgojs/medusa-integrations/tree/main/integration-tests/feed-yandex) workspace:

```bash title="Terminal"
cd integration-tests/feed-yandex
```

Make sure your `.env.test` file includes the following variables: `DB_USERNAME`, `DB_PASSWORD`:

```bash title="Terminal"
cp .env.test.template .env.test
```

Then, run tests:

```bash title="Terminal"
# Run module tests
# These verify the internal logic, such as services and models
yarn test:integration:modules

# Run integration tests
# Integration tests include tests for API Routes and Workflows
yarn test:integration:http
```

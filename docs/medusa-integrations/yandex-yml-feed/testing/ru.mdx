# {frontmatter.title}

Для запуска тестов перейдите в рабочее пространство [`integration-tests/feed-yandex`](https://github.com/gorgojs/medusa-integrations/tree/main/integration-tests/feed-yandex):

```bash title="Terminal"
cd integration-tests/feed-yandex
```

Убедитесь, что в файле `.env.test` присутствуют следующие переменные: `DB_USERNAME`, `DB_PASSWORD`:

```bash title="Terminal"
cp .env.test.template .env.test
```

Затем, запустите тесты:

```bash title="Terminal"
# Run module tests
# These verify the internal logic, such as services and models
yarn test:integration:modules

# Run integration tests
# Integration tests include tests for API Routes and Workflows
yarn test:integration:http
```

# {frontmatter.title}

В этом руководстве вы узнаете, как просматривать и редактировать параметры интеграции Robokassa в Medusa Admin через [модуль интеграций](/medusa-modules/integration).

## Просмотр данных Robokassa

Чтобы открыть страницу с настройками Robokassa:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → Robokassa**.

Откроется страница настроек Robokassa, где можно просматривать параметры доступа Robokassa, параметры формирования чеков и поведения оплаты.

![Общий вид настроек Robokassa](/static/robokassa/ru/settings-overview.png)

---

## Редактирование параметров доступа Robokassa

В первой секции страницы можно изменить логин магазина, алгоритм хеширования и два пароля.

Чтобы отредактировать параметры доступа:

1. Перейдите в **Настройки → Интеграции → Robokassa**.
2. В секции **Доступы** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените логин магазина, алгоритм хеширования и два пароля.
5. Нажмите **Сохранить**.

![Редактирование параметры доступа](/static/robokassa/ru/edit-credential.png)

---

## Редактирование параметов формирования чеков

Секция **Чеки** хранит данные для формирование онлайн-чеков по 54-ФЗ.

Чтобы отредактировать параметры формирования чеков:

1. Перейдите в **Настройки → Интеграции → Robokassa**.
2. В секции **Чеки** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели обновите тип системы налогообложения, cтавки НДС по умолчанию для товаров и доставки.
5. Нажмите **Сохранить**.

![Редактирование параметов чеков](/static/robokassa/ru/edit-receipt.png)

---

## Редактирование поведения оплаты

Секция **Поведение** определяет тип поведения платежей.

Если включено автосписание платежа, используется одностадийная оплата. Если оно выключено, то двухстадийная оплата.

Чтобы изменить поведение оплаты:

1. Перейдите в **Настройки → Интеграции → Robokassa**.
2. В секции **Поведение** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените настройку автосписания и режим проведения платежей.
5. Нажмите **Сохранить**.

![Редактирование поведения оплаты](/static/robokassa/ru/edit-behavior.png)

## Добавление платежного провайдера

Чтобы добавить отображаемый в витрине магазина платежного провайдера Robokassa:

1. Перейдите в **Настройки → Регионы**.
2. Выберите ваш регион.
3. В первой секции нажмите на меню действий в заголовке секции.
4. Выберите **Редактировать**.
5. В открывшемся модальном окне:
![Добавление платежного провайдера](/static/robokassa/ru/add-payment-provider.png)
   - Добавьте **Robokassa** в платежные провайдеры.
6. Нажмите **Сохранить**.

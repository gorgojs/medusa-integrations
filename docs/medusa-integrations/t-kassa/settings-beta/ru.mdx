# {frontmatter.title}

В этом руководстве вы узнаете, как просматривать и редактировать параметры интеграции T-Kassa в Medusa Admin через [модуль интеграций](/medusa-modules/integration).

## Просмотр данных Т-Касса

Чтобы открыть страницу с настройками Т-Касса:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции → Т-Касса**.

Откроется страница настроек Т-Касса, где можно просматривать параметры доступа Т-Касса, параметры формирования чеков и поведения оплаты.

![Общий вид настроек Т-Касса](/static/tkassa/ru/settings-overview.png)

---

## Редактирование параметров доступа Т-Касса

В первой секции страницы можно изменить ключ терминала и пароль.

Чтобы отредактировать параметры доступа:

1. Перейдите в **Настройки → Интеграции → Т-Касса**.
2. В секции **Доступы** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените ключ терминала и пароль.
5. Нажмите **Сохранить**.

![Редактирование параметры доступа](/static/tkassa/ru/edit-credential.png)

---

## Редактирование параметов формирования чеков

Секция **Чеки** хранит данные для формирование онлайн-чеков по 54-ФЗ.

Чтобы отредактировать параметры формирования чеков:

1. Перейдите в **Настройки → Интеграции → Т-Касса**.
2. В секции **Чеки** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели обновите версию формата фискальных данных, систему налогообложения, cтавки НДС по умолчанию для товаров и доставки.
5. Нажмите **Сохранить**.

![Редактирование параметов чеков](/static/tkassa/ru/edit-receipt.png)

---

## Редактирование поведения оплаты

Секция **Поведение** определяет тип поведения платежей.

Если включено автосписание платеж, используется одностадийная оплата. Если оно выключено, то двухстадийная оплата.

Чтобы изменить поведение оплаты:

1. Перейдите в **Настройки → Интеграции → Т-Касса**.
2. В секции **Поведение** нажмите на меню действий в заголовке секции.
3. Выберите **Редактировать**.
4. В открывшейся боковой панели измените настройку автосписания.
5. Нажмите **Сохранить**.

![Редактирование поведения оплаты](/static/tkassa/ru/edit-behavior.png)

---

## Добавление платежного провайдера

Чтобы добавить отображаемый в витрине магазина платежного провайдера Т-Касса:

1. Перейдите в **Настройки → Регионы**.
2. Выберите ваш регион.
3. В первой секции нажмите на меню действий в заголовке секции.
4. Выберите **Редактировать**.
5. В открывшемся модальном окне:
![Добавление платежного провайдера](/static/tkassa/ru/add-payment-provider.png)
   - Добавьте **TKassa** в платежные провайдеры.
6. Нажмите **Сохранить**.

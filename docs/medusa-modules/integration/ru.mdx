# {frontmatter.title}

Модуль интеграций позволяет любому плагину описывать свои опции и даёт администраторам магазина настраивать их как **интеграции** прямо в админке, без правок `medusa-config` и передеплоя. Он генерирует admin CRUD API и валидацию, поэтому вам не нужно писать модели данных, роуты или формы.

Модуль интеграций пригодится разработчикам Medusa, которые создают плагины, провайдеры или кастомные модули с настраиваемыми параметрами (ключи API, учётные данные, режимы, вебхуки) и не хотят вручную собирать страницы UI, слой данных и валидацию для каждого из них.

## Возможности

- **No-code конфигурация в Medusa Admin:** Учётные данные и опции управляются в разделе Настройки, без правок `medusa-config`/env и без передеплоя.
- **Не зависит от типа провайдера:** Работает для любого типа провайдера (оплата, доставка, контент, уведомления, ERP и другие), а также для любого плагина или кастомного модуля Medusa.
- **Декларативный дескриптор (`defineIntegration`):** Опции, секции настроек, валидация и проверка соединения в одном объявлении.
- **Гибкая типизация опций и валидация:** Типизированные поля (`string`, `url`, `email`, `uuid`, `number`, `boolean`, `enum`, `json`) с правилами на уровне опции и между секциями, условной видимостью и read-only-полями.
- **Шифрование секретов на месте (at-rest):** Поля с пометкой `secret` шифруются (AES-256-GCM) и никогда не уходят в браузер.
- **Несколько экземпляров:** Настраивайте один и тот же провайдер несколько раз, каждый со своими параметрами (например, несколько аккаунтов).
- **Проверка соединения:** Проверьте учётные данные в стороннем сервисе прямо из админки.
- **Типизированный резолв в рантайме:** Потребители читают провалидированные расшифрованные опции; неполные или выключенные опции не резолвятся, поэтому черновики не «протекают» в рантайм.
- **Настраиваемый UI админки:** Секции можно менять местами ([LayoutComposer](https://docs.medusajs.com/resources/admin-components/components/layout-composer)); если готовых секций недостаточно, соберите любой UI для своих опций с помощью кастомных виджетов.
- **Обзор интеграций:** Находите доступные интеграции прямо в админке.

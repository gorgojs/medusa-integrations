# {frontmatter.title}

В этом руководстве вы узнаете, как перевести UI настроек интеграции в Medusa Admin.

В дескрипторе нет отображаемого текста, только i18n-ключи. Admin подставляет каждый ключ на языке пользователя, поэтому один дескриптор работает на всех языках, для которых ваша интеграция поставляет переводы.

## Какие поля задаются i18n-ключами

Эти поля дескриптора принимают i18n-ключ, а не текст:

- `displayName` и `description` интеграции;
- `title` каждой секции;
- `label`, `hint` и `placeholder` каждого параметра;
- `valueLabels` параметра типа `enum`, по ключу на значение.

Всё остальное на странице модуль переводит сам, включая метку категории, статусы и действия. Его собственный интерфейс переведён на 34 языка из тех, что поддерживает Medusa Admin.

## Добавление переводов

Модуль интеграций построен на [переводах Admin в Medusa](https://docs.medusajs.com/learn/fundamentals/admin/translations), поэтому переводы находятся там же, где их ищет Medusa в любом плагине, в `src/admin/i18n/index.ts`.

Храните по JSON-файлу на язык с теми же ключами, что и в дескрипторе:

```json title="src/admin/i18n/json/en.json"
{
  "my": {
    "name": "My Payments",
    "credentials": "Credentials",
    "apiKey": "API key",
    "sandbox": "Sandbox mode"
  }
}
```

Вложенность выбираете вы. Ключ вида `my.apiKey` указывает во вложенные объекты, здесь `"my": { "apiKey": ... }`, так же, как его читает `t("my.apiKey")`.

Затем экспортируйте все языки из `src/admin/i18n/index.ts`:

```ts title="src/admin/i18n/index.ts"
import en from "./json/en.json" with { type: "json" }
import ru from "./json/ru.json" with { type: "json" }

export default {
  en: { translation: en },
  ru: { translation: ru },
}
```

При сборке панели администратора Medusa объединяет эти переводы с переводами самой Admin, поэтому ключи дескриптора, сгенерированные секции и ваши [собственные виджеты](/medusa-modules/integration/custom-sections) пользуются одними и теми же переводами. В виджете вызывайте `t()` из `useTranslation` с теми же ключами.

## Если перевода нет

Если у ключа нет перевода на языке пользователя, Admin показывает английский перевод. Если нет и английского, Admin показывает сам ключ, например `my.apiKey`, поэтому пропущенный перевод заметен на странице.

## Что не переводится

Сообщение `message`, которое ваши [правила валидации](/medusa-modules/integration/validation) передают в `addIssue`, остаётся обычным текстом, и Admin показывает его как есть. То же относится к `message`, которое возвращает `testConnection`. Пишите эти сообщения на языке, который читают администраторы вашего магазина, или делайте их короткими и техническими.

## Переводы и поиск

Admin ищет в списке интеграций по переведённым названию и описанию, а в истории изменений по переведённым названиям интеграций и полей. Ключ без перевода ищется как сам ключ.

История изменений хранит вместе с изменением ключ метки каждого поля. Поле, которое вы позже уберёте из дескриптора, сохранит в истории читаемое название, пока его перевод остаётся в вашем плагине.

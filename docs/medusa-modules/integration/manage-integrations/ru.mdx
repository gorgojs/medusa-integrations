В этом руководстве вы узнаете, как управлять интеграциями в Medusa Admin.

## Просмотр списка интеграций

Чтобы открыть список интеграций:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции**.

Откроется список всех интеграций, зарегистрированных в проекте. В каждой строке показаны название и иконка провайдера, версия пакета и автор, описание, категория и статус. Серый значок рядом с названием содержит идентификатор, под которым провайдера знает Medusa, например `pp_…` у платёжного провайдера или `fp_…` у провайдера доставки, а в остальных категориях собственный ключ интеграции `int_…`. Список можно фильтровать по категории и искать по названию, описанию или идентификатору интеграции.

![Список интеграций](/static/integration/ru/integrations-overview.webp)

Меню действий в конце строки включает, выключает, проверяет или удаляет настроенную интеграцию, не открывая её страницу. Чтобы открыть страницу интеграции, нажмите на её строку.

### Статусы интеграций

Статус жизненного цикла показывается всегда и может быть одним из следующих:

| Статус | Описание |
| --- | --- |
| Не настроено | Ни одна секция настроек ещё не сохранена. |
| Не завершено | Часть секций сохранена, но не все обязательные поля заполнены или заполненные значения не проходят валидацию. |
| Включено | Интеграция полностью настроена и включена. Провайдер получает её параметры во время выполнения. |
| Выключено | Интеграция полностью настроена, но выключена. Провайдер перестаёт получать её параметры, как будто она не настроена. |

Если провайдер поддерживает проверку соединения, рядом со статусом жизненного цикла показывается ещё один, отдельный статус по результату последней проверки:

| Статус | Описание |
| --- | --- |
| Подключено | Последняя проверка соединения прошла успешно. |
| Ошибка подключения | Последняя проверка соединения завершилась ошибкой. |

Пока проверка соединения ни разу не запускалась, этот статус не показывается.

У платной интеграции Gorgo список и страница интеграции показывают ещё и результат проверки лицензии. Когда первая проверка завершилась, в блоке лицензии на странице интеграции появляется кнопка **Проверить**, которая сразу повторяет проверку. Как лицензируются платные плагины, читайте в разделе [Лицензии на платные плагины](/licensing).

Каталог показывает интеграции, доступные для Medusa: и уже зарегистрированные в проекте, и те, которые ещё можно добавить. Чтобы открыть его, нажмите **Найти интеграции** над списком.

## Настройка интеграции

Пока интеграция не настроена, её страница показывает все секции с пустыми полями, кроме полей, которым провайдер задал значение по умолчанию. Отдельного действия для первой настройки нет. Сохранение любой секции с заполненными полями создаёт настройку.

Чтобы настроить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Нажмите на меню действий в заголовке нужной секции.
4. Выберите **Редактировать**.
5. Заполните обязательные поля в открывшейся боковой панели.
6. Нажмите **Сохранить**.

![Настройка интеграции](/static/integration/ru/configure-integration.png)

Модуль проверяет значения секции перед сохранением. Новая интеграция включена по умолчанию, поэтому её статус сменится с **Не завершено** на **Включено**, как только сохранённые значения целиком пройдут валидацию. Какие правила может объявить провайдер, читайте в руководстве [Валидация параметров интеграции](/medusa-modules/integration/validation).

## Проверка соединения

Некоторые провайдеры поддерживают проверку соединения. Она подтверждает, что провайдер принимает введённые значения, ещё до того как интеграция будет работать по-настоящему. Пункт проверки появляется в меню, только если провайдер её поддерживает, а интеграция включена и полностью настроена.

Чтобы проверить соединение:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Проверить соединение**.

Результат проверки появится в уведомлении.

В меню действий строки интеграции в списке пункт **Проверить соединение** появляется при тех же условиях.

![Проверка соединения](/static/integration/ru/test-connection.png)

Помимо ручной проверки, модуль раз в сутки, в 03:00 по часам сервера, заново проверяет каждую включённую интеграцию, провайдер которой это поддерживает. Статус соединения показывает результат последней проверки, ручной или плановой. Включённая, но ещё не завершённая интеграция не проходит плановую проверку с текстом `Not configured`, поэтому показывает **Ошибка подключения**, пока вы не закончите настройку.

## Редактирование секции

Секции настроенной интеграции редактируются так же, как при первой настройке.

Чтобы изменить секцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Нажмите на меню действий в заголовке нужной секции.
4. Выберите **Редактировать**.
5. Измените значения полей в открывшейся боковой панели.
6. Нажмите **Сохранить**.

Поле с секретом, например ключом API, показывает только то, что значение задано. Оставьте его пустым, чтобы сохранить прежнее значение, или введите новое, чтобы заменить его.

## Включение и отключение интеграции

Выключенная интеграция сохраняет свои настройки, но провайдер перестаёт их получать, как будто интеграция не настроена.

Действие доступно, как только у интеграции есть сохранённые настройки, полные или нет. Незавершённая интеграция в любом случае сохраняет статус **Не завершено**, поэтому о переключении сообщает только уведомление.

Чтобы включить или выключить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Включить** или **Выключить**.

---

## Удаление интеграции

Удаление стирает только сохранённые данные интеграции, например токены и остальные значения секций. Сам провайдер остаётся зарегистрированным в `medusa-config.ts` и снова появится в списке как ненастроенный. Чтобы полностью убрать провайдера, удалите его запись из `providers` в `medusa-config.ts`.

Удаление попадает в [историю изменений](/medusa-modules/integration/change-history) вместе со снимком значений, которые были настроены.

Чтобы удалить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Удалить**.
5. Подтвердите удаление.

---

## История изменений

Модуль записывает каждое изменение настроек интеграции вместе с автором, временем и изменёнными полями. Страница интеграции показывает её последние изменения, а кнопка **История изменений** над списком открывает изменения всех интеграций в одной таблице.

Как искать и фильтровать изменения и открывать подробности изменения, читайте в руководстве [Просмотр истории изменений в Medusa Admin](/medusa-modules/integration/view-change-history).

# {frontmatter.title}

В этом руководстве вы узнаете, как управлять интеграциями в Medusa Admin.

## Просмотр списка интеграций

Чтобы открыть список интеграций:

1. Откройте Medusa Admin.
2. Перейдите в **Настройки → Интеграции**.

Откроется список всех интеграций, зарегистрированных в проекте: название и иконка, автор, описание и категория. Для каждой интеграции показан статус. Список можно фильтровать по категории и искать по названию.

![Список интеграций](/static/integration/ru/integrations-overview.png)

### Статусы интеграций

Статус жизненного цикла показывается всегда и может быть одним из следующих:

| Статус | Описание |
| --- | --- |
| Не настроено | Ни одна секция настроек ещё не сохранена. |
| Не завершено | Часть секций сохранена, но не все обязательные поля заполнены или заполненные значения не проходят валидацию. |
| Включено | Интеграция полностью настроена и включена: провайдер получает её параметры в рантайме. |
| Выключено | Интеграция полностью настроена, но отключена: провайдер перестаёт получать её параметры, как будто она не настроена. |

Если провайдер поддерживает проверку соединения, рядом со статусом жизненного цикла показывается ещё один, отдельный статус по результату последней проверки:

| Статус | Описание |
| --- | --- |
| Подключено | Последняя проверка соединения прошла успешно. |
| Ошибка подключения | Последняя проверка соединения завершилась ошибкой. |

Пока проверка соединения ни разу не запускалась, этот статус не показывается.

## Поиск и добавление интеграции

В каталоге показаны интеграции, которые ещё не зарегистрированы в проекте, наряду с уже зарегистрированными.

Чтобы добавить новую интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Нажмите **Найти интеграции**.
3. Найдите нужную интеграцию.
4. Нажмите **Добавить**.
5. Следуйте инструкции по установке в открывшемся модальном окне: она содержит команду установки, фрагмент регистрации в `medusa-config.ts` и шаги настройки, которые нужно выполнить после перезапуска сервера — у каждого блока кода есть своя кнопка копирования.
6. Перезапустите сервер.

После этого интеграция появится в списке со статусом **Не настроено** и будет готова к настройке.

![Поиск интеграций](/static/integration/ru/browse-integrations.png)

## Настройка интеграции

Пока интеграция не настроена, её страница показывает секции с пустыми обязательными полями. Никакого отдельного действия для первого запуска нет: сохранение любой секции с заполненными полями и создаёт настройку.

Чтобы настроить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Нажмите на меню действий в заголовке нужной секции.
4. Выберите **Редактировать**.
5. Заполните обязательные поля в открывшейся боковой панели.
6. Нажмите **Сохранить**.

![Настройка интеграции](/static/integration/ru/configure-integration.png)

## Проверка соединения

Некоторые провайдеры поддерживают проверку соединения: она подтверждает, что введённые ключи принимаются провайдером, ещё до того как интеграция будет использована на практике. Если провайдер такую проверку не поддерживает, соответствующего пункта в меню действий не будет.

Чтобы проверить соединение:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Проверить соединение**.

Результат проверки появится в уведомлении.

![Проверка соединения](/static/integration/ru/test-connection.png)

## Редактирование секции

Секции настроенной интеграции редактируются точно так же, как при первой настройке.

Чтобы изменить секцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Нажмите на меню действий в заголовке нужной секции.
4. Выберите **Редактировать**.
5. Измените значения полей в открывшейся боковой панели.
6. Нажмите **Сохранить**.

---

## Включение и отключение интеграции

Отключённая интеграция сохраняет свои настройки, но провайдер перестаёт их получать, как будто интеграция не настроена.

Чтобы включить или отключить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Включить** или **Отключить**.

---

## Удаление интеграции

Удаление стирает только сохранённые данные: токены и остальные значения секций. Сам провайдер как источник интеграции при этом не удаляется: он по-прежнему зарегистрирован в `medusa-config.ts` и снова появится в списке как ненастроенный. Чтобы полностью убрать провайдера, удалите его запись из `providers` в `medusa-config.ts`.

Чтобы удалить интеграцию:

1. Перейдите в **Настройки → Интеграции**.
2. Откройте нужную интеграцию.
3. Откройте меню действий у названия интеграции.
4. Выберите **Удалить**.
5. Подтвердите удаление.
